The Models

Live
intelligence.

NBA AI pairs two purpose-built models to analyse every possession in real time. An XGBoost shot-quality regressor scores each attempt using distance, angle, defender proximity, and shot-clock context. A PyTorch MLP takes that score plus game state to output a rolling win probability — refreshed every three seconds via WebSocket.

Both models ship as pre-trained artifacts so the app runs immediately without a separate data pipeline. The synthetic training generator is included so anyone can retrain or fine-tune with real tracking data.

Shot QualityXGBoost — distance, angle, defender dist, shot clock, situation
Win ProbabilityPyTorch MLP — score diff, time, possession, fouls, shot quality
Live Datanba_api — scoreboard + play-by-play, polled every 3 seconds
Push LayerFlask-SocketIO — prediction events broadcast to all clients

Capabilities

Features

Live Scoreboard

Detects active NBA games automatically and polls play-by-play every three seconds — score, possession, latest event, and shot context all update in real time.

Shot Quality Model

XGBoost regressor scores every shot attempt using distance, angle, defender distance, shot clock, and game situation — quantifying shot difficulty on every possession.

Win Probability

PyTorch MLP converts game state into a live win-probability curve, incorporating shot quality as an input alongside score differential, time remaining, and foul counts.

Playoff Dashboard

Standings, schedule, team form, player leaders, sentiment signals, and alerts — a full playoff-season view updated alongside live games.

Game Predictions

On-demand matchup predictions for any two teams, returned with a plain-English explanation of the pick based on model features and current form.

Player & Team Pages

Profile views for every playoff player and team — with refreshable contextual news pulled from ESPN and season stats from nba_api.
