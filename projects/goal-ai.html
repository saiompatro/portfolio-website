Goal AI

ML-first FIFA World Cup match prediction, team insights, and player analysis — combining XGBoost, LightGBM, and a PyTorch ensemble with SHAP explainability and natural-language summaries.

GitHub ↗ ← All Projects

The Model

Ensemble
intelligence.

Goal AI uses an ensemble of three models to predict FIFA World Cup match outcomes. XGBoost serves as the primary predictor, validated against LightGBM and a PyTorch feed-forward network, with final selection based on validation log-loss and Brier score.

Beyond predictions, SHAP values decompose every prediction into its contributing factors — so you can see exactly why the model favours one team over another. Hugging Face summarisation models then translate these factors into readable natural-language insights for each team and player.

PrimaryXGBoost — selected by validation log-loss + Brier score
EnsembleLightGBM + PyTorch FFN + Logistic Regression baseline
ExplainabilitySHAP — per-prediction feature decomposition
InsightsHuggingFace summarisation for natural-language analysis
StorageSupabase — artifacts, sample predictions, player data

Features

Match Prediction

Win/draw/loss probabilities for any matchup using historical World Cup data, form, squad stats, and tournament context.

Player Analysis

Deep stats and performance metrics for individual players — with ML-generated natural-language summaries that highlight strengths and weaknesses.

Team Insights

Team-level analysis covering squad depth, tactical tendencies, historical tournament performance, and predicted group-stage outcomes.

Explainability

SHAP beeswarm and waterfall charts show which features drove each prediction — making the model transparent and interpretable.

ML Pipeline

Automated end-to-end pipeline: data ingestion → feature engineering → training → evaluation → SHAP explanation → Supabase push.

A clean, interactive frontend built with Next.js App Router — covering match predictions, team pages, player profiles, and the model card.
