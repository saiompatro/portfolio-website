Signal Engine

Data-driven
equity signals.

NiveshSutra ingests daily market data for all 50 Nifty 50 stocks, computes technical indicators, runs FinBERT sentiment analysis on financial news, and produces explainable buy/hold/sell signals through a weighted composite score.

The hybrid signal engine blends three signal sources — technical momentum, NLP sentiment, and price momentum — into a single composite score. Portfolio allocations are optimised via Mean-Variance Optimization tailored to each user's risk profile.

composite = 0.4 × technical + 0.3 × sentiment + 0.3 × momentum

technical = 0.3·RSI + 0.3·MACD + 0.2·BB + 0.2·OBV
momentum = mean(5d_return, 20d_return, SMA_crossover)
sentiment = avg(positive_prob − negative_prob) via FinBERT

Score → Signal:
  ≥ 0.5 → strong_buy
  ≥ 0.2 → buy
  ≥ −0.2 → hold
  ≥ −0.5 → sell
  < −0.5 → strong_sell

Features

What it does

Risk-Profiled Onboarding

A 5-question questionnaire maps users to conservative, moderate, or aggressive risk profiles — shaping every downstream recommendation.

Stock Explorer

All 50 Nifty stocks with candlestick charts (TradingView), live technical indicators, and FinBERT sentiment gauges updated daily.

Hybrid Signals

Explainable buy/sell recommendations with decomposed scores — see exactly how much of the signal comes from technicals vs. sentiment vs. momentum.

Portfolio Optimizer

Mean-Variance Optimization with CAPM expected returns and Ledoit-Wolf covariance shrinkage, tailored to the user's risk profile.

Sentiment Analysis

ProsusAI/FinBERT NLP model scores financial news headlines from Moneycontrol and Economic Times in real time.

Automated Alerts

Notifications for signal changes, significant sentiment shifts, and portfolio drift beyond user-defined thresholds.
